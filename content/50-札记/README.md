# 研究札记

> 未定论的思考、正在验证的假设、读到的材料与反驳。
>
> 这一区**允许不完整、允许后来被推翻**。保留演进过程本身是有价值的——
> 一个只展示成品结论的研究站，可信度反而更低。

## 约定

- 每篇札记标注日期与状态：`探索中` / `已验证` / `已推翻`
- 被推翻的札记**不删除**，加一行「后续修正」并链接到新结论
- 札记中的观点若被验证并稳定，再提升到 [框架](../15-DIA框架详解/) 或 [实践](../20-实践/)
