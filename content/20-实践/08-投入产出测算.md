# 投入产出测算

> **2026-08-23 新增。**外部审查指出一处自相矛盾：[开工前 12 问](06-开工前12问.md) 的 Q12 要求客户给出「什么情况下叫停」的量化失败判据，**而全站不提供任何测算工具来支撑这个回答**。
>
> 本页给出一个粗算模型。**它的精度不高，但它的作用不是算准，是让不成立的场景在立项前就暴露出来。**

---

## 一、先说这个模型的局限

**〔判断〕** 必须先说清楚，否则它会被误用：

- 它算的是**单场景**，不是平台整体投资
- 它的输入（决策频次、单次节省时间、错误代价）**通常只有粗略估计**，误差可以到 ±50%
- **它算不出本体复用带来的收益**——那是第二个场景之后才显现的，而复用率的经验曲线目前没有公开数据（见 [模块五 5.3](../10-方法论总结/05-模块五-整合视图与展望.md) 未解问题 ④）
- 因此：**它适合用来否决明显不成立的场景，不适合用来证明一个场景值得做**

**这是它最主要的用法：一个负向筛子。**

---

## 二、收益侧

### 2.1 三类收益，只算得清前两类

| 类型 | 可测量性 | 算法 |
|---|---|---|
| **人力节省** | 可算 | 决策频次 × 单次节省时间 × 加载人力成本 |
| **决策质量改善** | 部分可算 | 需要 A/B 分流才有因果结论（见 [模块三 3.8](../10-方法论总结/03-模块三-Agentic系统设计与编排.md)） |
| **速度/覆盖扩大** | 通常算不清 | 「原来只能看 Top 100，现在能看全量」的价值，多数情况下无法量化 |

**〔判断〕** **不要把第三类写进测算。**把算不清的收益写进 ROI，是让整份测算失去可信度的最快方式。诚实的做法是把它单列为「未计入的潜在收益」。

### 2.2 人力节省

```
年度人力节省 = 决策频次(次/年) × 单次节省时间(小时) × 加载人力成本(元/小时)
```

**三个容易高估的地方**：

| 高估点 | 修正 |
|---|---|
| **把「决策耗时」当成「可节省时间」** | 系统只替代信息搜集与草拟，人仍要审核。**L1/L2 阶段的实际节省通常是耗时的 30–60%**，不是 100% |
| **忽略新增的工作** | 例外处理、抽检、评测维护、Owner 的口径裁决——这些是**新增**的人力，必须减掉 |
| **忽略过渡期的双倍工作** | 影子运行期人要同时做旧动作和看新建议（见 [模块四 4.6](../10-方法论总结/04-模块四-行动闭环与企业采纳.md)） |

**修正后**：

```
净人力节省 = 决策频次 × 单次节省时间 × 替代率 × 人力成本
           − 例外处理与抽检的年度人力
           − 评测与口径维护的年度人力
```

> **替代率的取值**：L1 建议约 0.2–0.4；L2 草拟约 0.4–0.7；L3 限额自动约 0.7–0.9。
> **⚠️ 这组数字是我的经验估计，非实测，没有公开研究支持。**使用时应当由团队按自己的场景重新设定，并在项目结束后回填实测值。

### 2.3 决策质量改善

只有在能做 A/B 分流时才计入。计算方式：

```
年度质量收益 = 受影响业务量 × 指标改善幅度 × 单位价值
```

**没有 A/B 分流就不要计入这一项**，改为「未计入的潜在收益」。反事实不可观测的问题见 [电商剖面](../30-行业剖面/01-电商.md)。

## 三、成本侧

### 3.1 一次性投入（首个场景）

**〔判断〕** 以下人力估算基于我的经验，**非实测**，且高度依赖企业的 M 级起点：

| 角色 | 投入（人月，M1 起点） | 说明 |
|---|---|---|
| 业务 Owner | 0.5–1 | 兼职，但**不可缺**——缺了就是口径无人裁决 |
| 数据工程 | 1.5–3 | 接入最小数据集 + 断言校验；M0 起点要翻倍以上 |
| 平台/后端工程 | 2–4 | 本体实现、行动契约、权限贯穿、证据链 |
| AI 工程 | 1–2 | 工具设计、评测集、智能层 |
| 项目/交付管理 | 0.5–1 | 跨部门协调，尤其数据合同谈判 |
| **合计** | **5.5–11 人月** | **首个场景**，不含平台通用能力的长期建设 |

**这个数字的用法**：不是拿来做预算，是拿来做**量级判断**。如果一个场景的年度净收益低于首次投入的 30%，基本可以判定不成立。

### 3.2 年度运行成本

| 项 | 说明 |
|---|---|
| **模型调用成本** | 决策频次 × 单次成本。注意 `A2`：Agent 约为 chat 的 **4 倍** token，多 Agent 约 **15 倍** |
| 基础设施 | 存储、计算、可观测 |
| **治理人力** | 抽检、评测维护、口径裁决、证据链审计——**最常被漏掉的一项** |
| 变更与升级 | 模型版本变更导致的回归测试 |

**单次决策成本的算法**：

```
单次成本 = (输入 token × 输入单价 + 输出 token × 输出单价) × 平均轮次
```

**〔判断〕** 这里最容易低估的是**平均轮次**。Agent 每一轮都会重发历史上下文，所以成本不是线性的。这是 [模块三 3.4 上下文经济学](../10-方法论总结/03-模块三-Agentic系统设计与编排.md) 直接对应的经济后果。

## 四、四条否决线

**〔判断〕** 满足任何一条，这个场景在经济上不成立，**不要做**：

| # | 否决线 | 理由 |
|---|---|---|
| **1** | 年度净收益 < 首次投入的 **30%** | 回本超过三年，而模型与业务都会在三年内变化 |
| **2** | 单次决策成本 > 单次节省的人力成本 | 直接亏损。（示例判断：一次决策花 3 元、只省 2 分钟人工，若人力成本 60 元/小时则节省仅 2 元——**算不过来**） |
| **3** | 决策频次 < 每周一次，且单次价值不高 | 积累不出证据，自治级别永远升不上去，治理成本摊不薄 |
| **4** | 治理人力 > 节省人力 | 用一个新岗位换掉一个旧岗位，没有净收益 |

**〔判断〕** 第 4 条最常被忽略。企业 AI 的隐性成本主要不是算力，是**维护它所需要的人**。

### 两项无法计入、但必须在决策时说明的成本

**〔判断〕** 它们算不出金额，但会影响决策，不能因为算不出就不提：

| 成本 | 说明 |
|---|---|
| **技能维持的效率代价** | 保留人工例外处理、保留一定比例的无辅助处理——这些**故意不优化**的部分会拉低账面收益，但它们是[退出选项的保险](09-自建vs采购与退出剧本.md)。**把它们优化掉，等于用一笔看不见的负债换一点看得见的收益** |
| **叫停时的接管成本** | 运行数年后若叫停，团队可能已无能力按旧方式作业。这项成本随时间单调上升且账面不可见 |

## 五、把测算接进开工前 12 问

Q12「什么情况下你们会叫停这个项目」现在有了可回答的形式：

```
叫停条件（立项时冻结）：
  □ 第 N 个月，L1 建议的人机一致率仍低于 __%
  □ 第 N 个月，仍未取消任何一个旧动作
  □ 单次决策成本连续 __ 周高于 __ 元
  □ 累计投入超过预算 __%，而净收益未达预期的 __%
  □ 治理人力超过节省人力
```

**〔判断〕** 这份条件必须**在立项时写下并冻结**，理由与评测集冻结相同：事后议定的失败判据没有裁决能力。

## 六、测算表模板

```
场景：____________________          日期：______

【收益】
  决策频次            ______ 次/年
  单次决策耗时        ______ 小时
  替代率              ______（L1: 0.2-0.4 / L2: 0.4-0.7 / L3: 0.7-0.9，经验估计）
  加载人力成本        ______ 元/小时
  ─ 毛人力节省        ______ 元/年
  − 例外处理与抽检    ______ 元/年
  − 评测与口径维护    ______ 元/年
  = 净人力节省        ______ 元/年

  质量改善收益        ______ 元/年（仅在可 A/B 分流时填）
  未计入的潜在收益    ______________（文字描述，不计入合计）

  = 年度收益合计      ______ 元/年

【成本】
  一次性投入          ______ 人月 × ______ 元/人月 = ______ 元
  年度模型调用        ______ 元/年
  年度基础设施        ______ 元/年
  年度治理人力        ______ 元/年
  = 年度运行成本      ______ 元/年

【结论】
  年度净收益 = 年度收益 − 年度运行成本 = ______ 元
  回本周期   = 一次性投入 ÷ 年度净收益 = ______ 年

  否决线检查：
  □ 年度净收益 ≥ 首次投入 30%？
  □ 单次决策成本 < 单次节省人力成本？
  □ 决策频次 ≥ 每周一次（或单次价值足够高）？
  □ 治理人力 < 节省人力？

  四项全过 → 可进入立项；任一不过 → 换场景
```
