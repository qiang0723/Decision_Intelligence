# 成熟度诊断：M0–M2 + 覆盖率

> **2026-08-23 更正。**此前是 M0–M4 五级。外部审查指出 **M3/M4 只是把自治级别 L2/L3 换了个名字重说一遍**（M3「系统草拟，人一键确认」= L2；M4「限额自动」= L3），而本页自己的规则三已经写了「有价值的是有多少决策进入闭环，不是最高做到第几级」。
> 现收敛为 **M0–M2 三级（组织与语义状态）+ 覆盖率指标（自动化程度）**。

> 用途：给企业一个自我定位的坐标，以及「下一步该做什么」的明确答案。
> 这是与 CIO/CTO 第一次对话时最有效的工具——它把「我们该不该做 AI」变成「我们现在在哪一格」。

---

## 五个层级

| 级别 | 名称 | 特征 | 决策如何发生 | 典型症状 |
|---|---|---|---|---|
| **M0** | 手工 | 数据散在各系统与 Excel | 靠经验、开会、人工拉数 | 「这个数我要问一下财务」 |
| **M1** | 可见 | 有 BI/看板，数据集中 | 人看报表后决定 | 「报表有了，但还是按经验做」 |
| **M2** | 有语义 | 本体成型，口径唯一 | 人基于统一事实决定 | 「终于不吵口径了」 |

> M3/M4 已取消。自动化程度改用**覆盖率**表达，见下。

## 每一级的准入判据

不是「感觉差不多」，而是可验证的：

### M1 可见
- [ ] 核心业务数据已集中，可查询
- [ ] 有面向业务的报表/看板，且被实际使用

### M2 有语义
- [ ] 核心指标有唯一权威实现与业务 Owner
- [ ] 关键对象有本体定义（对象规范卡齐备）
- [ ] 跨系统标识映射已建立
- [ ] 数据血缘可查询
- [ ] **不存在绕过本体的业务语义路径**

### 覆盖率（取代原 M3/M4）

自动化程度直接用 **L 级决策计数**表达：

```
某域的成熟度报告 = M2 ＋「该域 12 个已识别决策中，5 个 ≥L2，2 个 ≥L3」
```

好处：不与 L 级重复；能表达混合状态（原模型无法回答「M3 但只有一个场景在 L2」）；奖励覆盖率而非最高级别。

### 进入 L2 覆盖（原 M3）的判据
- [ ] 至少一个决策场景实现完整写回闭环
- [ ] 行动有完整十一要素契约
- [ ] 写回到权威系统，无第二套真相
- [ ] 有冻结的评测集，且系统达到上线标准
- [ ] 有完整证据链，可追溯任意一次执行
- [ ] 有人机权责矩阵，且有旧动作被取消

### 进入 L3 覆盖（原 M4）的判据
- [ ] 至少一个场景稳定运行在 L3 及以上
- [ ] 自治晋级/降级条件已定义且自动生效
- [ ] 持续在线评测与抽检机制运行中
- [ ] 成本可归因、有配额与熔断
- [ ] R3 行动满足 [四条件](../10-方法论总结/04-模块四-行动闭环与企业采纳.md)，否则保留人闸
- [ ] 人工推翻率被跟踪且处于低位

## 三条使用规则

### 规则一：M2 是分水岭，不可跳过

M0 → M1 是数据工程问题，钱能解决。
**M1 → M2 是组织问题，钱解决不了。**

M2 的实质不是建了一个语义层，而是企业**接受了「某个人对某个口径有裁决权」**。这是权力的重新分配，通常是整个演进过程中最难的一步。

跳过 M2 直接上 M3 的项目，会在上线三个月后陷入口径战争，然后被架空。

### 规则二：级别是按域算的，不是按企业算的

一家企业完全可以是：
- 供应链域：M3
- 营销域：M1
- 财务域：M2

**报告成熟度时必须按域说明并附覆盖率，笼统说「我们公司是 M2」是没有意义的。**这也意味着推进策略应当是逐域打穿，而不是全域齐头并进。

### 规则三：不要为了升级而升级

M4 不是所有场景的目标。

- 低频决策停在 L1/L2 完全合理——自动化的收益不足以覆盖治理成本（见 [投入产出测算](08-投入产出测算.md) 的四条否决线）
- 不满足四条件的 R3 场景，天花板本来就在 L2
- **有价值的是「有多少决策进入了闭环」，而不是「最高做到了第几级」**

## 与架构五层 + 四约束的对应

| 跃迁 | 主要在建的层 |
|---|---|
| M0 → M1 | F 事实（接入与集中） |
| M1 → M2 | **O 本体** + F 事实（口径与血缘）+ A 行动契约 |
| 提升 L2 覆盖 | **A 行动** + D 决策界面 + I 智能（L1–L2） |
| 提升 L3 覆盖 | I 智能（L3）+ 运行约束（成本、熔断、可观测）+ 无人值守身份 |
| 全程 | **四条横切约束**（权限 · 证据 · 可逆 · 运行） |

## 快速诊断（10 分钟版）

问企业五个问题，基本能定位：

1. 「上季度的 GMV 是多少」——多久能得到答案，三个部门答案一致吗？
   → 不一致 = M1 以下
2. 「客户」这个概念，有没有一个人有权裁决它的定义？
   → 没有 = M2 未达成
3. 有没有任何一个系统建议，能被一键执行写回业务系统？
   → 没有 = L2 覆盖率为 0
4. 有没有任何一个决策，系统在限额内自动做了？
   → 没有 = L3 覆盖率为 0
5. 最近一次 AI 给出错误建议，多久被发现的？能查到原因吗？
   → 查不到 = 证据链缺失，无论前面几级都要补

更完整的诊断见 [开工前 12 问](06-开工前12问.md)。
