# 企业 AI 平台 · 方法论研究站

个人研究站项目。当前阶段：**方法论整理与站点搭建**，暂不做工程实施。

## 定位

> 面向企业决策者（CIO/CTO）与潜在合作方，
> 系统回答：**企业为什么用不起来 Palantir 式的决策智能系统，以及怎么才用得起来。**

> **2026-08-23：本内容库经过一次外部审查并整体修订。**
> 审查报告见 [docs/评审报告-外部审查.md](docs/评审报告-外部审查.md)，修订说明见 [docs/修订记录-20260823.md](docs/修订记录-20260823.md)。
> 主要变化：补齐外部引用与数据来源、更正 Palantir 本体模型的错误表述、修复权限模型在无人值守自动执行下的漏洞、六层改为五层 + 四条约束、90 天改为 120 天、新增合规安全 / 投入产出 / 自建采购三块内容。

核心方法论：**决策智能架构（DIA）**
记忆锚点：**一个中心，两个方向，四条约束。**

## 两条平级主线

| 主线 | 回答什么 | 规模 |
|---|---|---|
| **方法论总结** | 这个领域是怎么回事：是什么、有哪些流派、怎么判断 | 5 模块 30 主题 · 约 5h25m |
| **实践** | 明天做什么：诊断、路线、工作坊、模板、清单、测算、退出、供应商评估 | 10 套工具 |

两者是平级的，不是「理论 + 应用」的层级关系。

## 标注体系与它的适用范围

方法论总结全文区分三种内容性质：**〔共识〕**（领域内已验证，**必须有可点击出处**）· **〔争议〕**（存在分歧，列出主要立场）· **〔判断〕**（我的个人观点，可能被推翻）。

**必须说清的两条边界**：

1. **标注体系只覆盖 `content/10-方法论总结/`。**`15-DIA框架详解/`、`20-实践/`、`30-行业剖面/` 三个目录**整体属于〔判断〕**——它们是我的方法论主张，不声称是领域共识。
2. **〔共识〕必须有出处。**所有外部数据集中在 [引用与数据来源](content/40-参考/04-引用与数据来源.md)，正文以 `E1`、`A3`、`P1` 等编号引用。没有出处的〔共识〕已在 2026-08-23 的修订中全部降级为〔判断〕。

一份不区分共识与个人观点的方法论总结，读者无法评估它的可靠性；而一个没有出处的〔共识〕标签，读者同样无法评估——它只是把「我认为」换成了「大家都认为」。

## 本地运行（Docker）

```bash
make up
```

启动后访问 **http://localhost:8081**。常用命令：

| 命令 | 作用 |
|---|---|
| `make up` | 启动（后台常驻，`restart: unless-stopped`） |
| `make down` | 停止并移除容器 |
| `make logs` | 查看日志 |
| `make status` | 查看状态 |
| `make check` | 校验所有页面可访问 + 编码正确 + 站内链接无断链 |
| `make open` | 用默认浏览器打开 |
| `make build` | 只构建镜像（内容打包进镜像，可整体搬走或分享） |

**换端口**：`make up PORT=9000`，或在项目根目录建 `.env` 写 `SITE_PORT=9000`。
默认用 8081 是因为本机 8080 已被占用。

### 服务提供什么

| 路径 | 内容 |
|---|---|
| `/` | 站点（12 页展示层） |
| `/content/` | **内容库 Markdown 真身**，可在浏览器里直接以纯文本阅读、可按目录浏览 |
| `/docs/` | 信息架构 · 内容路线图 · 外部审查报告 · 修订记录 |
| `/README.md` | 本文件 |
| `/healthz` | 健康检查 |

### 编辑即生效

compose 以**只读方式**把 `site/`、`content/`、`docs/` 挂进容器，改完文件刷新浏览器即可见，**不需要重新 build**。
`docker build` 单独构建时会把内容打包进镜像，那份是自包含的快照。

### 不用 Docker 的话

站点是纯静态 HTML/CSS，无依赖、无构建步骤，直接 `open site/index.html` 也能看
（区别：`file://` 下不能浏览 `/content/` 目录，Markdown 会触发下载而不是直接显示）。

## 内容维护约定

- **Markdown 是真身**，站点是展示层的精编版
- **〔共识〕必须有可点击出处**，否则降级〔判断〕（2026-08-23 立）
- **具体数字必须有出处**，或明确标注为「示意」「经验估计」
- **作为架构地基使用的外部概念，必须核实到一手来源**——二手转述可作线索，不可作依据
- **同一主张在全库的标注等级必须一致，以最弱的那次为准**
- 每篇必须回答「读完之后明天做什么」
- 反面内容（失败、反模式、不做清单、未解问题、覆盖不到的失败原因）不少于正面内容的 1/3
- 札记允许不完整、允许被推翻；被推翻的不删除，加修正说明
